# EquationFlow

EquationFlow is a Remastered version of Fitting Pipes(A Balancing addition and subtraction expressions game made for Grade School Kids). EquationFlow features an overhaul of design to make it much more minimalistic and simple for users. 

# Quick Start
1. Open Project: Launch IntelliJ IDEA, select Open, and choose the project root folder.

2. Maven Import: Wait for the progress bar at the bottom right to finish. If a "Maven projects need to be imported" popup appears, click Load Maven Project.
- Note: If dependencies are not recognized, click the "Reload All Maven Projects" icon in the Maven tool window (top right).

3. Set Sources Root: If the folder src/main/java is not blue, right-click it and select Mark Directory as > Sources Root.

4. Execute Main Class: Navigate to src/main/java/com/example/demo1/BasicGameApp.java. Right-click the file and select Run 'BasicGameApp.main()'.
